# Phe-be Smith | Dance Educator, Choreographer & Youth Development Artist

Official portfolio and interactive web platform for **Phe-be Smith**: Master dance educator, choreographer, performer, and youth development leader inspiring confidence, creativity, discipline, and lifelong learning through movement.

## ✨ Features

- **Interactive Showcase & Curriculum**: Highlights dance disciplines including Modern/Contemporary, Hip Hop, Ballet, Step/Tap, Liturgical Sacred Dance, and STEM & Movement.
- **Audio & Video Integration**: Built-in media showcases with interactive lightbox players.
- **Booking & Workshop Request Wizard**: Seamless interactive inquiry flow for schools, studios, institutions, and residencies.
- **Responsive & Accessible Design**: Built with clean vanilla CSS tokens, fluid layouts, and smooth animations.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve with a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
